# 📊  Netflix Movies & TV Shows SQL Analysis
![Netflix logo](https://github.com/iam-anjalirawat/SQL_Project_Netflix/blob/main/Netflix%20Logo)

# 📌 Project Overview
This project explores the Netflix Movies & TV Shows dataset through SQL by solving 15 real-world business problems. The analysis covers content distribution, audience ratings, release trends, country-wise production, genre popularity, director and actor insights, and content classification. Throughout the project, I applied SQL for data cleaning, transformation, exploratory data analysis (EDA), and business intelligence to derive meaningful insights from raw data.

# 🔍 Key Business Questions Answered
- Compared the distribution of Movies and TV Shows available on Netflix.
- Identified the most common content ratings.
- Retrieved all movies released in a specific year.
- Analyzed the top countries producing Netflix content.
- Found the longest movie available on Netflix.
- Identified content added in the last five years.
- Analyzed content created by specific directors.
- Identified TV Shows with more than five seasons.
- Explored genre-wise distribution of Netflix content.
- Examined year-wise growth of Netflix content in India.
- Analyzed Documentary content available on Netflix.
- Identified records with missing director information.
- Retrieved content featuring Salman Khan.
- Ranked the top Indian actors appearing in Netflix titles.
- Classified content as **Good** or **Bad** based on keywords in the description using SQL `CASE` statements.
